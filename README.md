# Poker Defense Calculator v2

## 表示項目

- Pot Size
- Bet Size
- Bet Size (% Pot)
- Pot Odds
- MDF
- Required Folds
- Optimal Bluff Frequency
- Value : Bluff
- Risk : Reward

## 100 pot / 75 bet の計算結果

- Bet Size: 75.0% Pot
- Pot Odds: 30.0%
- MDF: 57.1%
- Required Folds: 42.9%
- Optimal Bluff Frequency: 30.0%
- Value : Bluff: 2.33 : 1
- Risk : Reward: 1 : 1.33

`42.9%` は Pot Odds ではなく、ブラフが即時利益を得るための Required Folds
（必要フォールド率、1 - MDF）です。
